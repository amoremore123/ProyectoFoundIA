# Fotos de los datos de ejemplo (seed.sql)

`database/seed.sql` publica tres objetos con fotos en `/uploads/objetos/...`. Esas fotos vienen dentro
de la API (carpeta `uploads/`; solo esa se publica) y Spring las sirve cuando no están en el volumen de subidas, así funcionan en
cualquier base sin copiar archivos. Son las mismas fotos de referencia de la web
(`frontend/usuario/public/imagenes/FOTOGRAFIAS.md`), descargadas de Unsplash (https://unsplash.com/license).
No son objetos reales del campus.
